**Guideline (2026-11-18, measured with `minimal-floor.mjs`, window always-on-top):** one infinite,
non-composited CSS animation (the REC `box-shadow` pulse) costs **~2.1 % of this machine on an
empty Electron page** and ~2.4 % on a content page (GPU process ~1.6 %, renderer 0.5–0.8 %) — the
same as in Streamlabs. Cause: a frame per display refresh (240 Hz here) × full-window composite of a
2566×1521 px window. Not framework-related. Rule: **no infinite animations in always-visible UI**;
throttle to a few updates/s or animate only `transform`/`opacity` (and even those still cost
compositor frames). Note: a covered (occluded) window produces no frames — floor runs must keep the
window visible (`minimal-app` now uses `alwaysOnTop`).
